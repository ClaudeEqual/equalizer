# Эквалайзер для macOS: упрощённое ТЗ

Личная программа для одного человека. Не для профессионалов: всё должно быть понятно без объяснений.

## Что делает

Меняет звучание **всего звука на Mac** (музыка, YouTube, фильмы, игры): можно добавить низких частот (бас) и убрать резкие высокие.

## Что входит

1. **10-полосный эквалайзер**: 10 вертикальных ползунков, от самого низкого баса (32 Гц) до самых высоких (16 кГц).
   - Каждый ползунок от −12 до +12 дБ.
   - Под ползунками подписи «Низкие / Средние / Высокие».
   - Двойной клик по ползунку сбрасывает его в ноль.
   - Изменения слышны сразу, без щелчков и пауз.
2. **Один большой переключатель Вкл/Выкл.** Когда выключено, звук идёт как обычно.
3. **Готовые пресеты одной кнопкой**: «Ровно», «Бас ↑ Верха ↓» (стоит по умолчанию), «Больше баса», «Мягкий звук», «Больше высоких», «Голос», «Кино», «Тихо ночью».
4. **Свои пресеты**: сохранить текущие настройки под своим названием и удалить ненужные.
5. **Защита от хрипа**: громкость автоматически немного снижается при сильном усилении, а встроенный ограничитель не даёт звуку искажаться.
6. **Иконка в строке меню** с тем же эквалайзером, чтобы не держать окно открытым.
7. **«Запускать при включении Mac»**: одна галочка.
8. Настройки запоминаются после перезапуска.
9. При подключении наушников или смене устройства вывода эквалайзер сам переключается на новое устройство.

## Технически

- macOS 14.2 и новее, Apple Silicon и Intel.
- Swift + SwiftUI, системный захват звука через Core Audio Process Tap. Сторонние драйверы (BlackHole и т.п.) не нужны.
- Звук обрабатывается только на компьютере, никуда не записывается и не отправляется.
- Установка: скачать `.dmg`, перетащить в «Программы», один раз разрешить запуск и доступ к звуку.

## Что убрано из исходного ТЗ и почему

| Убрано | Почему |
|---|---|
| Режимы 15/20/31/41 полоса | Для обычного человека 10 полос достаточно, больше только путает |
| Спектроанализатор | Красиво, но для настройки звука не нужно |
| Автокоррекция, AI-ассистент | Сложно, нужен внешний сервис, пользы мало по сравнению с пресетами |
| Advanced Bass (Sub/Punch/Body/Mud) | Бас уже регулируется тремя левыми ползунками |
| 24 эффекта, 13 «пространств» | Профессиональные инструменты, легко испортить звук |
| Коррекция наушников (736 моделей) | Нужны лицензированные измерения |
| Коррекция помещения | Нужен измерительный микрофон |
| Громкость отдельных приложений, сцены, несколько выходов | Сильно усложняет программу и интерфейс |
| Управление с iPhone, аккаунты, синхронизация, лицензии | Программа личная, это не нужно |
| Balance, ручной Preamp | Заменены автоматической защитой от перегрузки |
