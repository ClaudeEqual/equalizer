# Как получить и установить Эквалайзер

## Часть 1. Собрать приложение (делается один раз, ~10 минут, с любого компьютера)

Mac для сборки не нужен: бесплатный сервер GitHub соберёт программу сам.

1. Зарегистрируйтесь на https://github.com (если аккаунта ещё нет).
2. Справа вверху нажмите **«+» → New repository**.
   - Repository name: `equalizer`
   - Выберите **Public**, чтобы друг мог скачать файл по ссылке. Если не хотите, выберите Private и потом просто перешлите ему файл `.dmg`.
   - Нажмите **Create repository**.
3. На открывшейся странице нажмите ссылку **«uploading an existing file»**.
4. Откройте папку `Equalizer` у себя на компьютере, выделите **всё её содержимое** (Ctrl+A), включая папку `.github`, и перетащите в окно браузера.
5. Внизу нажмите **Commit changes**.
6. Откройте вкладку **Actions**: там запустится сборка «Build Equalizer». Подождите 3–5 минут, пока не появится зелёная галочка.
7. Откройте главную страницу репозитория. Справа в разделе **Releases** появится сборка. Внутри лежит файл **Equalizer.dmg**: его и нужно скачать или переслать другу.

> Если во вкладке Actions пусто, значит папка `.github` не загрузилась. Нажмите **Add file → Create new file**,
> в имя файла впишите `.github/workflows/build.yml`, вставьте содержимое файла `build.yml` из папки и нажмите **Commit changes**.
>
> Если сборка покраснела (ошибка), откройте её, скопируйте текст ошибки и пришлите мне: я исправлю.

## Часть 2. Установка на Mac (для друга)

1. Откройте **Equalizer.dmg**.
2. Перетащите иконку **Equalizer** на папку **Applications (Программы)**.
3. Откройте Эквалайзер из «Программ» или через Launchpad.
4. macOS скажет, что не может проверить разработчика (программа не из App Store, это нормально):
   - нажмите **Готово**;
   - откройте **Системные настройки → Конфиденциальность и безопасность**;
   - прокрутите вниз и нажмите **«Всё равно открыть»**, потом введите пароль от Mac.
   Это нужно сделать только один раз.
5. Появится вопрос про доступ к системному звуку: нажмите **Разрешить**.
6. Готово. Звук всего Mac теперь идёт через эквалайзер.

## Как пользоваться

- **Переключатель справа вверху** включает и выключает эквалайзер.
- **Кнопки пресетов**: по умолчанию стоит «Бас ↑ Верха ↓» (больше баса, меньше резких высоких).
- **Ползунки**: левые отвечают за бас, правые за высокие. Двойной клик возвращает ползунок в ноль.
- **«Сохранить как свой»** запоминает текущие настройки под своим названием.
- Иконка эквалайзера есть и **в строке меню** вверху экрана, так что окно можно закрыть.
- **«Запускать при включении Mac»**: поставьте галочку, и эквалайзер будет включаться сам.

## Если что-то не так

- **Пропал звук.** Нажмите в программе **«Нет звука?»** и включите «Эквалайзер» в списке «Запись системного звука». Если не помогло, выключите эквалайзер переключателем или закройте программу: звук сразу станет обычным.
- **Сменили наушники или колонки.** Эквалайзер сам переключится на новое устройство примерно через полсекунды.
- Нужна **macOS 14.2 или новее** (меню  → «Об этом Mac»).
